🚀 Desafío JS #2 – Adivinanza y mini home con Flexbox

En este segundo desafío combiné **lógica en JavaScript** con **diseño en CSS**, sumando así nuevos conceptos clave para el desarrollo frontend.

---

✅ Interacción con el usuario (prompt y alert)  
✅ Comparación de valores y condiciones (`if`, `else`)  
✅ Número aleatorio con `Math.random()`  
✅ Validación de entrada del usuario  
✅ Flexbox para distribución visual de elementos

---

💻 ¿Qué hace este proyecto?

Este desafío tiene **dos partes**:

1. **Adivinanza numérica**  
   El programa genera un número aleatorio entre 1 y 10.  
   Luego le pide al usuario que adivine ese número.  
   Si acierta, recibe un mensaje de felicitación. Si no, se le muestra el número correcto.

2. **Mini Home con Flexbox**  
   Se construyó una página básica con HTML y se aplicó **Flexbox** para estructurar visualmente:
   - Un encabezado
   - Una sección principal con dos columnas
   - Un pie de página

---

🔧 Cómo probarlo

1. Abrí el archivo `index.html` en tu navegador.
2. Interactuá con la adivinanza al cargar la página.
3. Explorá el diseño aplicado con Flexbox.
