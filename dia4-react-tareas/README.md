# Desafío Día 4 – Lista de Tareas con React & Vite

¡Hola! Este es el proyecto correspondiente al **Día 4** del desafío de desarrollo web Full Stack, donde practico React combinando manejo de estado, eventos, y estilos para crear una app interactiva y moderna.

---

## 📋 Descripción

Aplicación sencilla para administrar una lista de tareas, con las siguientes funcionalidades:

- Crear tareas nuevas.
- Marcar y desmarcar tareas como completadas.
- Eliminar tareas individuales.
- Interfaz visual centrada en pantalla en formato **card**.
- Fondo de pantalla con imagen fija para un diseño atractivo y moderno.
- Uso de React con hooks (`useState`) para manejo del estado.
- Desplegada con Vite para un entorno rápido y optimizado.

---

## 🚀 Tecnologías usadas

- React (Hooks)
- Vite (bundler y dev server)
- CSS para estilos responsivos y visuales modernos

---

## 🎯 Características principales

- Estado local para tareas y entrada de texto.
- Validación simple para no crear tareas vacías.
- Listado dinámico con opción de marcar completado.
- Botones interactivos con efectos hover.
- Fondo fijo y card blanca con transparencia para buen contraste.
