# 📅 Día 4 - Lista de Tareas con React & Vite

¡Hola! Este es el proyecto correspondiente al **Día 4** del desafío de desarrollo web Full Stack.  
En esta ocasión desarrollé una app moderna de **lista de tareas**, enfocándome en estados, eventos y diseño visual.

---

## 🎯 Objetivos del desafío

- Consolidar el uso de **React** y hooks (`useState`).
- Crear una interfaz **centrada en pantalla** con diseño tipo **card**.
- Estilizar con CSS responsivo e imagen de fondo fija.
- Trabajar el control de entradas, validación y renderizado dinámico.

---

## 🧩 Funcionalidades principales

✅ Agregar tareas  
✅ Marcar tareas como completadas  
✅ Eliminar tareas individualmente  
✅ Validación para evitar entradas vacías  
✅ Interfaz centrada con fondo de imagen fijo  

---

## 🚀 Vista previa

> 🖼️ **Card centrada** sobre imagen de fondo fija  
> ✅ **Interacción en tiempo real**  
> 🎨 **Estilos modernos y minimalistas con efectos hover**

---

## 🛠️ Tecnologías utilizadas

- ⚛️ React (con `useState`)
- ⚡ Vite (dev server y bundler)
- 💅 CSS3 moderno (centrado, efectos, fondo fijo)
- 📷 Imagen fija desde Unsplash o local
