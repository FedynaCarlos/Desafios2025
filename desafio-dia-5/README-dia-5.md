# 🟦 Desafío Día 5 - Lista de Tareas Persistente con React + localStorage

Este proyecto forma parte del reto de desarrollo web diario. En el **Día 5** implementamos una lista de tareas (ToDo) usando **React.js** con **persistencia de datos en localStorage**, lo que permite guardar las tareas incluso si se recarga el navegador.

---

## 🚀 Tecnologías Utilizadas

- ✅ React.js (con Vite)
- ✅ JavaScript (ES6+)
- ✅ localStorage (Web API)
- ✅ CSS Modules
- ✅ HTML5 semántico

---

## 📋 Funcionalidades

- Agregar nuevas tareas
- Marcar tareas como completadas
- Eliminar tareas
- Interfaz con animaciones de hover
- Persistencia de datos usando `localStorage`

## 🧠 Aprendizajes del día

- Comprensión del ciclo de vida de los componentes (`useEffect`)
- Cómo sincronizar el estado de React con el almacenamiento local
- Buenas prácticas para trabajar con listas e identificadores únicos (`Date.now()`)
- Interacción con el DOM usando eventos de foco, hover y clic

## 🔧 Cómo ejecutar este proyecto

1. Clonar el repositorio
```bash
git clone https://github.com/FedynaCarlos/desafio-dia-5.git
cd desafio-dia-5
```

2. Instalar dependencias
```bash
npm install
```

3. Ejecutar la app
```bash
npm run dev
```
