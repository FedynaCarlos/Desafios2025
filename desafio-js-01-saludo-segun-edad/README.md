# 🚀 Desafío JS #1 – Saludo según edad

En este primer desafío trabajé con los siguientes conceptos de JavaScript:

✅ Variables (`let`)  
✅ Tipos de datos (`string`, `number`)  
✅ Conversión de datos (`parseInt`)  
✅ Estructuras de control (`if`, `else if`)  
✅ `prompt()` y `alert()` para interactuar con el usuario

## 💻 ¿Qué hace este script?

Pide el nombre y la edad al usuario, y según su edad muestra un mensaje personalizado:

- Si tiene entre **7 y 17 años**, se le recomienda estudiar JavaScript.
- Si tiene entre **18 y 39 años**, se lo motiva a crecer profesionalmente.
- Para otras edades, se informa que el desafío está orientado a un público muy específico.

---

#### 🔧 Cómo probarlo

1. Abrí el archivo `index.html` en tu navegador.
2. Completá los datos cuando se te pidan.
3. ¡Mirá el mensaje personalizado!

---

### 🧠 Aprendizajes

Este desafío me ayudó a practicar la interacción básica con el usuario, validación de datos y lógica de condiciones en JavaScript.
