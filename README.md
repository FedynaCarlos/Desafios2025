## 🧱 Día 4 - Lista de tareas con React & Vite

Este proyecto consiste en una aplicación sencilla para administrar tareas, con una interfaz centrada tipo **card** y un fondo fijo con imagen para mejor experiencia visual.

🔹 **Objetivo pedagógico:**  
Practicar React con hooks (`useState`), manejo de eventos, condicionales, y estilos CSS modernos. Además, usar Vite para un entorno de desarrollo rápido y optimizado.

🔹 **Resultado final:**  
Una app funcional donde se puede:

- Agregar nuevas tareas (no vacías).  
- Marcar o desmarcar tareas como **completadas** (checkbox).  
- Eliminar tareas individualmente.  
- Visualizar la lista en una tarjeta centrada con diseño responsive.  
- Fondo fijo con imagen para un look profesional.

## ⚙️ Cómo ejecutarlo localmente

1. Asegurate de tener **Node.js** y **npm** instalados.  
2. Cloná el repositorio:  
   ```bash
   git clone https://github.com/tu-usuario/nombre-repo.git
   cd nombre-repo/dia4-react-tareas
3. Instalá las dependencias:
 npm install
4. Ejecutá el servidor de desarrollo:
   npm run dev
5. Abrí la URL que te indica la consola (usualmente http://localhost:5173) en tu navegador.
