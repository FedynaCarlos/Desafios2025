## 🧱 Día 3 - Contador y lista interactiva en React

Este ejercicio consiste en una app construida con **React** que incluye:

- Un contador de tareas.
- Una lista de tareas interactivas con estado (hecho / no hecho).
- Botón para agregar nuevas tareas.
- Uso de `useState`, props, JSX y eventos como `onClick`.
- Estilo modularizado con CSS.

### Objetivos:

- Aplicar `useState` para manejar estados.
- Renderizado condicional y componentes reutilizables.
- Interacción dinámica con el usuario.
- Buenas prácticas de estructura y nombrado.

## ✅ Día 2 - Adivinanza y mini home con Flexbox

En este segundo desafío combiné **lógica en JavaScript** con **diseño en CSS**, sumando así nuevos conceptos clave para el desarrollo frontend.

### Funcionalidades

- ✅ Interacción con el usuario (prompt y alert)  
- ✅ Comparación de valores y condiciones (`if`, `else`)  
- ✅ Número aleatorio con `Math.random()`  
- ✅ Validación de entrada del usuario  
- ✅ Flexbox para distribución visual de elementos

### 🗂️ Cómo usarlo

1. Cloná este repositorio o descargalo en tu PC.  
2. Abrí el archivo `index.html` en tu navegador.  
3. Ingresá un número del 1 al 10 y hacé clic en "Probar suerte".

### Este desafío tiene dos partes:

#### 1. Adivinanza numérica

- El programa genera un número aleatorio entre 1 y 10.  
- Luego le pide al usuario que adivine ese número.  
- Si acierta, recibe un mensaje de felicitación. Si no, se le muestra el número correcto.

#### 2. Mini Home con Flexbox

- Página básica con HTML + CSS.  
- Uso de Flexbox para estructurar:
  - Encabezado
  - Sección principal en dos columnas
  - Pie de página

### 🔧 Cómo probarlo

1. Abrí el archivo `index.html` en tu navegador.  
2. Interactuá con la adivinanza al cargar la página.  
3. Explorá el diseño aplicado con Flexbox.

### 🧠 Aprendizajes

- Practicar lógica y validación de datos con JavaScript.  
- Usar Flexbox para estructurar contenidos de manera profesional.  
- Combinar interactividad + diseño en un solo proyecto.
