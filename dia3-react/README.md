# 📅 Día 3 - Lista de Tareas Interactiva con React

¡Hola! Este es el desafío del **día 3** de mi recorrido como **Desarrollador Web Full Stack**.  
En esta ocasión desarrollé una aplicación de **lista de tareas dinámica** con React.

---

## 🎯 Objetivos del desafío

- Aplicar conceptos fundamentales de **React**.
- Usar **`useState`** para manejar estados dinámicos.
- Desarrollar componentes reutilizables.
- Trabajar con eventos (`onClick`, `onChange`).
- Estilizar de forma clara y moderna, con fondo fijo.

---

## 🧩 Funcionalidades principales

✅ Agregar tareas  
✅ Marcar tareas como completadas  
✅ Borrar tareas individualmente  
✅ Mostrar la cantidad total de tareas  
✅ Fondo de pantalla fijo e interfaz centrada  

---

## 🚀 Vista previa

> 🖼️ **Diseño centrado** + **imagen de fondo fija** (parallax)  
> ✅ **Interacción en tiempo real** con cada tarea  
> 🎨 **Estilos modernos y responsivos**

---

## 🛠️ Tecnologías utilizadas

- ⚛️ React (Vite)
- 📦 JavaScript ES6+
- 💅 CSS moderno con Flexbox
- 🎨 Unsplash para fondo
- 🧠 Buenas prácticas y componentes separados
